
# ช่างนพ รับซ่อมแซมบ้านครบวงจร

บริการงานช่างฝีมือ ประสบการณ์ตรง งานละเอียด ซื่อสัตย์ ราคายุติธรรม 
(มีใบรับรองความรู้ความสามารถ ช่างไฟฟ้าภายในอาคาร ระดับ 1)

### 🛠️ รายการบริการของเรา
* **งานซ่อมแซมโครงสร้าง & ภายนอก:** ซ่อมผนังกำแพงแตกร้าว, แก้ปัญหาหลังคารั่วซึม, ทาสีบ้าน, ซ่อมประตูรั้วเหล็กและงานเชื่อม
* **งานระบบไฟฟ้า & ประปา:** ตรวจเช็กและซ่อมระบบไฟฟ้าภายในบ้าน, เปลี่ยนหลอดไฟ/ปลั๊ก/เบรกเกอร์, ซ่อมท่อประปาแตกรั่ว, เปลี่ยนก๊อกน้ำ/สุขภัณฑ์
* **งานบริการทำความสะอาด:** บริการฉีดล้างพื้นบ้าน ลานจอดรถ และล้างรถนอกสถานที่
* **งานตกแต่ง:** จัดสวนและทำบ่อน้ำพุขนาดเล็ก

---

### 📍 พื้นที่ให้บริการ
* โซนปากเกร็ด, ถนนสามัคคี, แจ้งวัฒนะ, หลักสี่, ถนนกำแพงเพชร 6 และพื้นที่ใกล้เคียง

### ⏰ เวลาที่ให้บริการ
* **วันจันทร์ - อาทิตย์:** ช่วงเย็น - ค่ำ เวลา 18.00 - 23.00 น. (รับงานซ่อมด่วนหลังเลิกงาน)
* **วันพุธ:** ให้บริการเต็มวัน
